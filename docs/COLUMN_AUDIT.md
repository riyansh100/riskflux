# Column Audit

Generated by `notebooks/01_eda.ipynb`. Every raw column is classified exactly once.

## target (1)

Source of the label.

`loan_status`

## split_or_filter_key (3)

## lc_decision_EXCLUDED_D4 (8)

`zip_code`, `addr_state`, `emp_title`
